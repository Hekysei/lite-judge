# Lite Judge

Легковесная асинхронная система автоматической проверки Python-задач на FastAPI с изоляцией решений в Docker-контейнерах, приёмом ответов через вебхуки (Яндекс Формы) и файловым хранилищем без использования БД.

## Возможности

- **Изолированный запуск кода:** каждая проверка выполняется в одноразовом Docker-контейнере без доступа к сети (`--net none`), с лимитом памяти (64 МБ), CPU и жёстким таймаутом.
- **Zero-database хранение:** задания, тесты и посылки студентов хранятся в обычных файлах и директориях.
- **Высокая скорость отклика:** состояние посылок и HTML-страницы кэшируются в оперативной памяти и обновляются точечно.
- **Асинхронная очередь:** параллельная обработка решений пулом фоновых воркеров.

## Переменные окружения

| Переменная | Обязательная | По умолчанию | Описание |
| :--- | :---: | :--- | :--- |
| `FORM_URL` | Да | `""` | Ссылка на форму отправки решений (например, Яндекс Форму). Если не указана, ссылка на главной странице скрывается. |
| `HOST` | Нет | `127.0.0.1` | IP-адрес, на котором запускается веб-сервер. |
| `PORT` | Нет | `8000` | Порт веб-сервера. |
| `MAX_WORKERS` | Нет | `17` | Количество параллельных воркеров, одновременно проверяющих посылки в Docker. |
| `DOCKER_IMAGE` | Нет | `python:3.11-alpine` | Docker-образ, внутри которого запускается код студентов. |
| `DOCKER_TIMEOUT` | Нет | `3` | Максимальное время выполнения одного теста в секундах. |
